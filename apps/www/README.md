At root apps/www folder, please create a new Next.js project with all the latest bun packages. Please do a web search and use all the latest npm packages. In that project, please use the following bun packages:
1. React Query
2. Motion
3. Drizzle ORM with turso db connections
4. 3D rendering setup with spline
5. Zustand for state management
6. Better Auth
7. Browser PGlite database package

```bash
git clone https://github.com/shadcn-ui/ui shadcn-ui && cd shadcn-ui && rm -rf .git && cd ..
git clone https://github.com/DavidHDev/react-bits && cd react-bits && rm -rf .git && cd ..
git clone https://github.com/midday-ai/midday && cd midday && rm -rf .git && cd ..
```
